Mary Anning’s plesiosaur

Plesiosaurus

A drawing of the living animal, and a historical plate of the skeleton. No invented length.

Drawing: Dmitry Bogdanov, CC BY-SA 3.0, via Wikimedia Commons. Artist’s concept, not a photograph. Drawing file page

There is no film of this animal made for this site. The picture behind the title is a drawing. The picture lower down is a historical skeleton plate, not a photograph of the bones.

What we know

  • Plesiosaurus dolichodeirus. A Paleobiology Database occurrence of the type is labeled Late Sinemurian. The same list stores that label on the Sinemurian bin, 199.5 to 192.9 million years ago. Those numbers are the whole Sinemurian stage on this timescale, not a measured span of only the late part. Paleobiology Database occurrence list
  • Mary Anning found the first articulated skeleton. The Natural History Museum in London tells that part of the story. Natural History Museum, London
  • The drawing behind the title is Dmitry Bogdanov’s concept of the living animal. It is not a photograph. The original file is 1800 pixels wide. This page serves 1800 pixels wide, not enlarged. Drawing file page
  • The picture below is J. Dinkel’s historical figure of a Lower Lias skeleton. The original file is 3505 pixels wide. This page serves 1920 pixels wide, not enlarged. Skeleton plate

What this page does not claim

  • No body length is written on the sources linked here, so this page does not draw a person beside the animal.
  • The pin is the Jurassic Coast already on the World Map, the Dorset and East Devon coast. It is not the museum in London, and it is not a drawing of the animal. The place marker was made for this site. Created by the Founder and SI.

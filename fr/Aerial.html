Meganeura

Un insecte géant de Commentry, en France. Le muséum de Paris date Meganeura monyi d’environ 300 millions d’années, au Carbonifère tardif, et donne 70 cm d’envergure. L’image est le lectotype, MNHN R51142.

Archaeopteryx

Un dinosaure à plumes des lagons du Jurassique tardif en Bavière, il y a environ 150 millions d’années.

Reconstitution. Durbed, CC BY-SA 3.0, via Wikimedia Commons. Artist’s concept. Page du fichier · Fossile. Emily Willoughby (emily.a.willoughby@gmail.com), CC BY-SA 4.0, via Wikimedia Commons. The original file is 3926 pixels wide. This page serves 1920 pixels wide, not enlarged. Page du fichier · Source: Bürgermeister-Müller-Museum, Solnhofen. Lien depuis la pièce de ce site.

Pterodactylus

Un ptérosaure des lagons de Solnhofen. La Paleobiology Database place le type de Pterodactylus antiquus dans le Tithonien, de 149,2 à 143,1 millions d’années sur cette échelle. La pièce de Solnhofen arrondit ces mêmes lagons à environ 150. L’image est un fossile, pas Archaeopteryx.

Dean Falk Schnabel, CC BY-SA 4.0, via Wikimedia Commons. The original file is 4128 pixels wide. This page serves 1920 pixels wide, not enlarged. Page du fichier · Source: Paleobiology Database, taxon 156644, localité type dans le calcaire tithonien de Solnhofen.

Argentavis

Argentavis magnificens, nommé par Campbell et Tonni, 1980, dans l’Huayquérien d’Argentine. Les occurrences Paleobiology Database de cette espèce sont rangées de 8 à 5 millions d’années. L’image est un squelette exposé à Trelew. Il n’est pas identifié ici comme le spécimen type.

Rique, CC0, via Wikimedia Commons. The original file is 4624 pixels wide. This page serves 1920 pixels wide, not enlarged. Page du fichier · Source: Campbell et Tonni, 1980. Les bacs de 8 à 5 millions d’années sont les occurrences Paleobiology Database, le second lien. · Source: Occurrences Paleobiology Database d’Argentavis magnificens.

Aigle de Haast

Un rapace de Nouvelle-Zélande. New Zealand Birds Online écrit qu’il a disparu il y a 500 à 600 ans, à peu près en même temps que les moas. L’image est une planche de crâne de Castle Rocks, dans le Southland, pas un portrait vivant.
